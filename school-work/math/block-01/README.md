## Fractions cheat row

| Op | Steps |
|----|--------|
| × | numerator×numerator / denominator×denominator → reduce |
| ÷ | Keep first → Change ÷ to × → Flip second → multiply → reduce |
| + / − | Find **LCD** → rewrite each numerator → add or subtract numerators only → keep LCD → reduce |

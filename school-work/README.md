## Fractions quick reminder

| Operation | Rule |
|-----------|------|
| **Multiply** | tops × tops, bottoms × bottoms, then reduce |
| **Divide** | Keep → Change → Flip, then multiply |
| **Add/Sub (LCD)** | new top = old top × (LCD ÷ old bottom); then add/sub tops only |
